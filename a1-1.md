# Test Cases for File Upload Feature

## 1. Introduction

The purpose of testing the file upload feature is to verify that users can successfully upload files and that the system correctly handles different file types, file sizes, invalid files, and upload errors.

## 2. Test Objectives

- Verify that users can upload files successfully.
- Verify that the system accepts supported file formats.
- Verify that the system rejects unsupported file formats.
- Verify that file size restrictions work correctly.
- Verify that appropriate error messages are displayed.
- Verify that uploaded files are stored correctly.
- Verify that users can cancel or remove uploaded files.

## 3. Test Cases

| Test Case ID | Test Scenario                                      | Test Steps                                                         | Expected Result                                                                 |
| ------------ | -------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| TC001        | Upload a valid file                                | 1. Open the upload page. 2. Select a valid file. 3. Click Upload.  | The file is uploaded successfully.                                              |
| TC002        | Upload a PDF file                                  | 1. Select a PDF file. 2. Click Upload.                             | The PDF file is uploaded successfully.                                          |
| TC003        | Upload an image file                               | 1. Select a JPG or PNG file. 2. Click Upload.                      | The image is uploaded successfully.                                             |
| TC004        | Upload an unsupported file type                    | 1. Select an unsupported file (e.g., .exe). 2. Click Upload.       | The system rejects the file and displays an error message.                      |
| TC005        | Upload a file exceeding the maximum size           | 1. Select a file larger than the allowed size. 2. Click Upload.    | The system rejects the file and displays a file size error.                     |
| TC006        | Upload an empty file                               | 1. Select a file with 0 bytes. 2. Click Upload.                    | The system handles the empty file according to the requirements.                |
| TC007        | Upload without selecting a file                    | 1. Open the upload page. 2. Click Upload without selecting a file. | The system displays a validation message.                                       |
| TC008        | Upload multiple files                              | 1. Select multiple files. 2. Click Upload.                         | All supported files are uploaded successfully, if multiple uploads are allowed. |
| TC009        | Cancel file upload                                 | 1. Select a file. 2. Start uploading. 3. Click Cancel.             | The upload is cancelled successfully.                                           |
| TC010        | Remove an uploaded file                            | 1. Upload a file. 2. Click Remove or Delete.                       | The selected file is removed successfully.                                      |
| TC011        | Upload a file with a special character in its name | 1. Select a file named `test_file@123.pdf`. 2. Upload it.        | The file is uploaded and its filename is handled correctly.                     |
| TC012        | Upload a file with a long filename                 | 1. Select a file with a very long filename. 2. Click Upload.       | The system handles the filename without breaking the interface.                 |
| TC013        | Upload a duplicate file                            | 1. Upload a file. 2. Upload the same file again.                   | The system handles duplicate files according to the requirements.               |
| TC014        | Interrupt the internet connection                  | 1. Start uploading a file. 2. Disconnect the internet.             | The system displays an appropriate upload failure message.                      |
| TC015        | Upload a corrupted file                            | 1. Select a corrupted file. 2. Click Upload.                       | The system rejects or appropriately handles the corrupted file.                 |
| TC016        | Check upload progress                              | 1. Select a large valid file. 2. Start uploading.                  | The system displays upload progress, if supported.                              |
| TC017        | Refresh the page during upload                     | 1. Start uploading a file. 2. Refresh the page.                    | The system handles the interrupted upload correctly.                            |
| TC018        | Upload a file with no extension                    | 1. Select a file without an extension. 2. Click Upload.            | The system accepts or rejects the file according to the requirements.           |
| TC019        | Verify uploaded file content                       | 1. Upload a valid file. 2. Download or open the uploaded file.     | The downloaded file matches the original file.                                  |
| TC020        | Upload a file after logging out                    | 1. Log out of the system. 2. Attempt to upload a file.             | The system prevents unauthorized uploads and requests authentication.           |

## 4. Boundary Value Testing

Boundary value testing checks whether the system correctly handles files at the limits of the allowed file size.

Example requirement: Maximum file size is 10 MB.

| Test Case ID | File Size | Expected Result                        |
| ------------ | --------- | -------------------------------------- |
| BVT001       | 0 MB      | Reject if empty files are not allowed. |
| BVT002       | 1 MB      | Upload successfully.                   |
| BVT003       | 9.99 MB   | Upload successfully.                   |
| BVT004       | 10 MB     | Upload successfully.                   |
| BVT005       | 10.01 MB  | Reject the file.                       |
| BVT006       | 15 MB     | Reject the file.                       |

## 5. Negative Testing

Negative testing verifies that the system handles invalid inputs and unexpected situations correctly.

| Test Case ID | Test Scenario                                 | Expected Result                                                    |
| ------------ | --------------------------------------------- | ------------------------------------------------------------------ |
| NT001        | Upload an executable file                     | The system rejects the file.                                       |
| NT002        | Upload a file with a misleading extension     | The system validates the actual file type, not just its extension. |
| NT003        | Upload a file with a malicious filename       | The system safely handles the filename.                            |
| NT004        | Upload a file with an invalid format          | The system displays an error message.                              |
| NT005        | Upload a file without permission              | The system denies the upload.                                      |
| NT006        | Upload a file while the server is unavailable | The system displays an appropriate error message.                  |

## 6. Security Testing

| Test Case ID | Test Scenario                                  | Expected Result                                               |
| ------------ | ---------------------------------------------- | ------------------------------------------------------------- |
| ST001        | Upload a file containing malicious code        | The system detects or safely handles the file.                |
| ST002        | Attempt to upload a script file                | The system blocks unsupported executable content.             |
| ST003        | Attempt to access another user's uploaded file | The system denies unauthorized access.                        |
| ST004        | Upload a file with a path traversal filename   | The system prevents unauthorized file access.                 |
| ST005        | Upload a file without authentication           | The system rejects the request if authentication is required. |

## 7. Test Summary

The file upload feature should be tested across the following areas:

| Testing Type           | Purpose                                                         |
| ---------------------- | --------------------------------------------------------------- |
| Functional Testing     | Verify that file uploads work correctly.                        |
| Positive Testing       | Verify that valid files can be uploaded.                        |
| Negative Testing       | Verify that invalid files are rejected.                         |
| Boundary Value Testing | Verify file size limits.                                        |
| Security Testing       | Verify that file uploads are secure.                            |
| Performance Testing    | Verify upload speed and system performance.                     |
| Usability Testing      | Verify that the upload process is easy to use.                  |
| Compatibility Testing  | Verify that uploads work across different browsers and devices. |

## 8. Conclusion

Testing the file upload feature helps ensure that users can upload files securely and successfully. The system should validate file types, enforce file size limits, handle errors properly, and protect uploaded files from unauthorized access.

Important: Expected results should be adjusted based on the actual project requirements. For example, the maximum file size, supported file formats, and multiple-file upload functionality may differ between systems.
